# Ecommerce Data Analytics Portfolio

This repository contains an end-to-end Ecommerce Data Analytics project utilizing **Python, SQL, Excel, and Power BI** to analyze customer behavior and churn patterns.

## 🛠️ Tools & Technologies Used
* **Python (Google Colab):** For Exploratory Data Analysis (EDA) and predictive modeling.
* **SQL:** For querying database and analyzing customer churn metrics.
* **Microsoft Excel:** For initial data cleaning and module-end descriptive analytics.
* **Power BI:** For building interactive business dashboards.

## 📂 Project Structure
* `Basic_Python_Module_End.ipynb` - Python Churn Analysis (Google Colab)
* `MODUL END - E-Commerce Customer Churn Analysis.sql` - SQL Queries
* `EXCEL MODULE END ASSIGNMENT-1).xlsx` - Excel Analytics Data
* `DOCUMENTATION-MINIPROJECT.pdf` - Project Documentation Report
